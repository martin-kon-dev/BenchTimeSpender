# BenchTimeSpender frontend

Vue 3 + TypeScript, served and built with Vite.

See the [repository README](../README.md) for local setup and the API request flow.

- `npm run dev`: start the development server.
- `npm test`: run component tests once.
- `npm run test:watch`: run tests while editing.
- `npm run build`: type-check and build production assets.

The `/api` proxy is configured for development only. Production hosting will be addressed in a later milestone.
